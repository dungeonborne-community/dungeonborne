# Forgejo

Our own git server for the workspace (docs/WORKSPACE_PLAN.md, step 5). Nothing is exposed: HTTP listens on
`127.0.0.1:3000`, Forgejo SSH on `127.0.0.1:2222`. Access goes through an SSH tunnel to the server.

## Install (root on the server)

```
scp ops/forgejo/* root@<vm>:/root/forgejo/
ssh root@<vm> bash /root/forgejo/install.sh 17.0.1
```

`install.sh` downloads the binary from codeberg.org, verifies sha256 and the GPG signature with the Forgejo release key, creates
the `git` user, `/var/lib/forgejo`, `/etc/forgejo/app.ini` (from `app.ini.template`; secrets are generated by
Forgejo itself, file 640 root:git), the `forgejo` service (600 MB memory limit, low priority so it yields to neighbours) and the
`forgejo-backup` timer (`forgejo dump` every night into `/var/backups/forgejo`, 7 days). Re-running updates the binary
and leaves app.ini alone. The VM runs in UTC (the backup timer fires at 04:30 UTC).

## First login (done by the owner)

1. Administrator (the password is shown once in your terminal; Forgejo asks to change it at first login):
   `ssh root@<vm> "sudo -u git forgejo admin user create --config /etc/forgejo/app.ini --admin --username <name> --email <email> --random-password"`
2. Tunnel: `ssh -N -L 3300:127.0.0.1:3000 -L 2222:127.0.0.1:2222 root@<vm>` and open `http://localhost:3300` in a browser.
3. Settings → SSH / GPG Keys → add your public key (`~/.ssh/id_ed25519.pub`).
4. Create the repository `dungeonborne` (private), then from `X:\DBDev\workspace`:
   `git remote add origin ssh://git@localhost:2222/<name>/dungeonborne.git` and `git push -u origin main` (with the tunnel open).

## Maintenance

- Log: `journalctl -u forgejo --since -10min`, files in `/var/lib/forgejo/log`.
- Update: `bash /root/forgejo/install.sh <new version>` (take a `forgejo-backup` first).
- Backups: `/var/backups/forgejo/forgejo-<date>.tar.gz`; restore with `forgejo restore` / unpacking as described in the docs.
