# content — data edited by people

Game tables and rules that designers and developers change (by hand or through Balance Studio). The code is in
`core/backend`; it only reads from here.

| Folder / file | What |
|---|---|
| `balance/tables/*.json` | server base: all game tables in our format; edits shared by every season |
| `balance/csv`, `balance/kit` | tables for people (CSV) and the Balance Studio kit (`docs/BALANCE.md`) |
| `seasons/base.toml` | common server and client mod settings for all seasons |
| `seasons/<season>/` | a season: its own tables, loot, flags; the active one is `seasons/active.txt` or the `SEASON` variable |
| `loot/` | loot per map (`loot.toml`) and analysis reports (`*_report.*`, generated by scripts — do not edit by hand) |
| `names/` | strings and names (`strings.tsv`, `strings_en.tsv`) |
| `match_checks.toml` | matchmaking checks: rarity and gear limits per map level |

**Season beats base:** a value from `seasons/<season>/` overrides the same one from `balance/tables` and `seasons/base.toml`.
A "this season only" edit goes into the season folder, a "forever" edit goes into the base. Season format — `docs/SEASONS_FORMAT.md`.

Build and check — from `core/backend`: `cargo xtask balance build` (tables → `core/backend/ExcelConfig` and the pak
`game/paks/balance`), `cargo xtask balance verify`, `cargo xtask season …`. Balance in detail — `docs/BALANCE.md`.
