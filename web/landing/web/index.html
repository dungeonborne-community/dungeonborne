The game

Descend. Loot. Get out.

Dungeonborne is a first-person dungeon where monsters and other delvers are both out to get you. This is the story of one raid: from gearing up in town to the moment you either step into a blue portal with full bags, or stay down in the dark with everything you brought.

  1. I

    Chapter I · Gearing up

    Take only what you can afford to lose

    It all starts in town. You put a kit together at the merchant, the auction house or the forge — and wear it: there is no chest in the dungeon to leave spares in. Whatever you carry is what you risk.

    • Insurance: for gold, an item survives one death, and your killer gets the insurance premium instead.
    • The merchant restocks every hour; the auction house has other players' items.
  2. II

    Chapter II · The descent

    Vote, hall, Start

    In the launcher you pick an instance and vote with everyone else: first for party size — solo, duo or trio — then for the map. Once the votes are in, the waiting hall opens. You press Start in the game, wait for the stragglers — and the gates rise.

    • The hall waits three minutes. Miss it and you sit this battle out, no penalty.
    • Solos fight solos, trios fight trios. Exceptions: Hard and Challenger Mode.
  3. III

    Chapter III · The dark

    The circle closes in

    Inside are corridors, monsters, chests and bosses. And other parties who came for the same thing you did. The safe zone shrinks in circles, and every time you have to decide: search one more room, or head for the exit before the circle catches you.

    • The rarer an item, the more properties it has.
    • The fallen can be searched: whatever they carried goes to the winner.
  4. IV

    Chapter IV · Portals

    Three colours, three choices

    As the circle shrinks, portals open inside it. The colour decides how your story ends.

    • Blue — the way out. Step in and the raid is over; everything you found is yours.
    • Red — deeper. To the second floor, where the loot is richer and the only way out is blue.
    • Purple — the throne room. From the first floor of Sinner's End — to the Shadow King.
  5. V

    Chapter V · Deeper

    Two maps, three difficulties

    Sinner's End is a two-floor dungeon: a red portal takes you down, and there is no way back up. Clouseau Castle is a one-floor gothic castle: no going deeper, only out through blue portals. Every map can be run on Normal, Classic or Hard — the higher, the richer the loot and the stricter the gear rules.

    • Castle on Normal: grey and green only, bags included — anything else goes to the stash when you enter.
    • Hard: everything you wear must be Epic or higher; parties of any size meet in one battle.
    • In the launcher the maps are called Dungeon and Castle.
  6. VI

    Chapter VI · The outcome

    Get out or stay down

    Escaped

    Everything you carried out is yours: to the stash, to sell, to the forge. Experience, battle pass quests, a line in your stats. You can go down again — richer this time.

    Fallen

    Your gear stays in the dungeon — whoever killed you takes it. Only insured items survive. Gear up again — and back down.

Epilogue · This server

The torches still burn

Dungeonborne can no longer be bought on Steam, but the dungeon hasn't closed. This server is run by the community: we brought back raids, lobbies and trading, built the launcher and fix bugs from your reports. The current season is Playtest — restarted on 11 November. Every season starts with a progress reset, and everyone begins at level 1.

  • A battle pass with quests, a leaderboard, character stats.
  • Challenger Mode: solos and duos against trios.
  • Coming soon — the Trial of Clotho: a three-on-three arena, a run of up to seven wins.
Download launcher Getting started

Four steps

Getting started

  1. 1

    Download the launcher

    It is a single exe, no install needed: put it in any folder and run it. Only download it here — the checksum is in “Help”. On first start Windows may warn about an unknown publisher — what to click is in “Help” too.

  2. 2

    Pick the game folder

    You need Dungeonborne installed. The launcher checks that your game version matches the server. Optionally, the settings can make Steam's “Play” open the launcher.

  3. 3

    Sign in with Discord

    The launcher opens your browser. Your account on the server is your Discord: no passwords, no SteamID.

  4. 4

    Play

    “Play” installs the mods and starts the game. Pick an instance tab, vote for group size and map, then press Start in the game — you land in the waiting hall.

What you need

  • Windows 10 or 11, 64-bit
  • Dungeonborne installed
  • A Discord account and membership in the project's Discord server

This is a playtest: the database may be reset and the server may go down for maintenance.

Launcher

It does everything itself

  1. Sign in with Discord

    Your account on the server is your Discord. No passwords, no borrowed SteamIDs.

  2. Mods install themselves

    Before launch the launcher downloads and checks the server's mods, and cleans up after the game.

  3. Instance lobby

    Pick an instance, vote for group size and map, join with Start in the game.

  4. Patch notes

    See what changed on the server right in the launcher — the same entries as in News below.

  5. Updates itself

    Installs only builds signed by the project — the server cannot swap them.

  6. Helps with connection

    If your ISP drops the connection, the launcher notices, suggests WARP and turns on a bypass for battles.

Help

If something goes wrong

Windows says “Windows protected your PC” or the antivirus complains

The launcher has no paid code signature, so SmartScreen shows “Windows protected your PC”: click “More info” → “Run anyway”. Antivirus software is sometimes wary of the launcher changing game files (installing mods) — that is expected.

But only download the launcher from this site and check the checksum: copies from chats and other sites may be tampered with.

How to check the file is genuine

Open PowerShell in the launcher's folder and run:

Get-FileHash .\DungeonborneLauncher.exe

The hash must match this one (version 1.7.0):

852D5FCE0788D2A4BF4284E439C777E936240C8EE74CCA127236B5C10C7BA283

Anti-cheat error “13-131084-2”

It happens when the game is started a few seconds after it was closed. Wait about 30 seconds after quitting and start again.

Sign-in fails, “CURLCode 28”, the lobby hangs

Some ISPs in Russia drop connections to our servers. The launcher notices this and shows a banner.

The free Cloudflare WARP or any VPN helps: turn it on and restart the launcher. If only battles lose connection, turn on “bypass for battles” in the launcher.

“Game version does not match the server”

The server is built for a specific Dungeonborne.exe, and the launcher will not start another version. Verify the game files in Steam and point the launcher to that folder.

Updated from an older version — what about hosts?

Nothing: since 1.7.0 the game needs no hosts, and the launcher no longer asks for administrator rights. If the hosts file still has lines from older versions, the launcher settings show a “Remove hosts changes” button — you can remove them or leave them.

Start in the game does nothing

Join an instance tab in the launcher first. Voting starts once enough players have joined; the hall lets you in while it is open and your group size matches the vote.

“Only members of the Discord server can sign in”

Members of the project's Discord server can play: join the server and sign in to the launcher again. During maintenance sign-in is closed to everyone except the admins.

Nothing helped — what to send the admins

The launcher's logs are in %LOCALAPPDATA%\DungeonborneLauncher\logs: attach relay.log and launcher.log. For connection problems the launcher banner has a “Copy report” button. Logs contain no tokens or passwords.
