Game server

        
Headless game instance with the DungeonborneRuServer mod (-dbserver), like dbtest\run.ps1 /
          play.ps1: status — dbtools\run\dbserver-status.json, commands — dbserver-control.txt.
          DS mode: clients press the game's native match button (match-mode.txt = native), the backend sends them to the
          server by itself (DS_POOL defaults to 127.0.0.1:7777@*, docs/DS_PIPELINE.md).

        

          
          
        

        

          
          
          
          
        

        

          
          
          
          
        

        

      

      

        
Server commands via the backend 

        
dev-app → backend (POST /admin/v1/host/command) → server; the mod runs it through the game's native
          UTgfCheatComponent and answers in dbserver-command-result.json. The server must be in phase
          ready. The backend waits up to 10 s for the mod's answer.
