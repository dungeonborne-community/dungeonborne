# Server Guide — fill in manually

New members see the Server Guide right after onboarding and the rules screen on join. Discord does not let bots configure it
(API response: "Bots cannot use this endpoint"), so it is filled in by hand:
**Server Settings → Onboarding → Server Guide**.

There is one guide for everyone, so it is in English, like all shared server texts. Translations of the other
info posts are in the "🌍" threads under them.

## 1. Welcome message

Author: the server avatar or someone from the team.

```
Welcome to Dungeonborne Community! The launcher signs in with your Discord, installs the mods and gets you into the game. Start with the steps below.
```

## 2. New member to-dos

| # | Title | Channel | Description | Action |
|---|---|---|---|---|
| 1 | Set up the launcher | `🚀・how-to-play` | Four steps to your first raid | View channel |
| 2 | Say hi | `💬・chat` | Tell us your class and how long you've played | Send a message |
| 3 | Find a party | `🤝・lfg` | Duo or trio — copy the template | Send a message |
| 4 | Share a screenshot | `🖼️・media` | Images and GIFs from your raids | Send a message |

Discord marks a step as done by itself: "View channel" — when the newcomer has opened the channel, "Send a message" — when they have sent their first message. If a member cannot see a step's channel, Discord does not show that step.

## 3. Resource pages

| Channel | Title | Description |
|---|---|---|
| `❓・faq` | FAQ | Common problems and fixes |
| `🆘・help` | Help | One problem — one post |
| `📢・announcements` | News | Releases, playtests, events |
| `🛠️・patch-notes` | Patch notes | Same notes as in the launcher |
| `📚・guides` | Guides | Builds and tips by class |
| `🏛️・about` | About us | Who we are and what we stand for |

## After setup

- `👋・welcome` stays: traffic from the site leads there, it is the path into the game. "Who we are" is in `🏛️・about`.
- Check the guide: **Server Settings → Onboarding → "Preview"**, or join with a test account.
- On the production server the guide is also filled in manually, after the move to the new structure.
