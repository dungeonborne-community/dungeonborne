Built 2026-10-31 to learn what the client does with server responses (pair to server `RPC_DUMP=1`). Doc: `docs/CLIENT_PROBE.md`.
- UE4SS mod `game/ue4ss/Mods/ClientProbe` (deployed to both installs, `mods.txt`): EVT (UTGFEventArgs objects incl. ErrorCode/TGFRsp),
  WIN (UTGFWindowArgs: alert/toast texts), CALL/ERR (hooks on UTGFService + network/window classes), F10 snapshot, F11 mark.
- 2026-11-04: LuaProbe moved out of shipped paks into debug-only pak `zzzzzzzz_LuaProbe_P`
  (`backups\debug\luaprobe`, `install_luaprobe.ps1` / `-Remove`; wraps the ORIGINAL match button + starts the probe).
  Never ship it: make_client_bundle.py skips *LuaProbe* paks. Mentions of RebuildPrivate below are history.
- UnLua `LuaProbe.lua` in pak `zzzzz_RebuildPrivate_P` (started from WBP_MatchMainButton.lua in lobby): LCALL/LRET module wrappers,
  FIELD = first read of UTGFProtoTgf*/FTGF* fields via patched metatable `__index` (unverified in game), optional TRACE (debug.sethook).
- Logs on G: (`probe/logs/<steam|alt>_<ts>_{ue4ss,lua}.log`) because MSIX virtualizes new %LOCALAPPDATA% folders ([[dungeonborne-msix-appdata]]);
  "alt" = install with `local_save.txt` (C:\Games\Dungeonborne). HDR line has steam_id = server open_id.
- Server now writes `rpc_dump/OUR.jsonl` (ts_ms, who, body) incl. hub pushes; per-file dumps restart seq each run (overwrite).
- `python -I tools/probe_timeline.py [--grep x|--kinds ERR,S2C|--fields|--summary]`; targets regenerated by `tools/py/gen_probe_targets.py`.
- 2026-10-31 v1 crashed the game at login (FMallocBinned2 realloc unrecognized block, via UE4SS.dll): never read
  FString/FText of live objects/params through UE4SS (likely frees the game's buffer); dump only root object + TGFProto*;
  probe skips instances with `-dbserver`/`-dbclient` (peer session's autoruns). Texts come from the Lua layer instead.
  Installs ship with `enabled = 0` until verified in game.
- Bisection 2026-10-31 (peer autoruns, `-dbprobe` forces probe on): events OK, Lua layer OK (FIELD via `__index` works);
  UE4SS RegisterHook on UTGFService functions crashes the game even with only simple params → `services = 0`, never enable.
- Client Lua entry `Main.lua` starts LuaPanda debugger only in editor — possible live debugger if socket lib exists (unchecked).
